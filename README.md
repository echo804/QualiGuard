## Configuration

Create .guardian.yaml in your project root:

```yaml
checkers:
  - static
  - style
  - security
  - complexity
  - dependency
ignore_patterns:
  - "__pycache__"
  - "node_modules"
max_line_length: 88
output_format: terminal
verbose: false
```
